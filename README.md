A demo of issue 11ty/eleventy#3788.

To install

1. Clone the repository, e.g.,
`git clone https://github.com/btrem/11ty_3788.git`.
1. Change to the directory you cloned into, e.g.,
`cd 11ty_3788`.
1. Run `npm install` at the command line.
1. Run `npm start`.

The resulting eleventy website will demonstrate and
explain the bug.
