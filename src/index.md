This 11ty project has a `test` shortcode.
The shortcode function takes a parameter with a default
value, `1`, and simply returns the parameter's type and
value to the calling template.

```js
eleventyConfig.addShortcode("test", function (num = 1) {
    console.log(`${this.page.inputPath} => type: ${typeof (num)}; value: ${num}`);
    return `type: ${typeof(num)}; value: ${num}`;
});
```

It also logs this info and the `page.inputPath` to the
console.

When the calling template's language is liquid, the
shortcode works whether I explicitly add the parameter
or rely on the default.
In both cases, it produces
<samp>type: number; value: 1</samp>.

However, when the template language is nunjucks, it only
works if a parameter is explicitly declared.
If there's no parameter, the shortcode fails, reporting
the type as `string` and providing no visible value.
Apparently, nunjucks calls the shortcode with the empty
string. In other words, {% raw %}`{% test %}`{% endraw %}
is equivalent to {% raw %}`{% test "" %}`{% endraw %}.
